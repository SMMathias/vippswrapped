# Vipps Wrapped

Studieprojekt, Multimediedesign, Erhvervsakademi Aarhus. Ikke tilknyttet Vipps MobilePay.

Eksamensprojekt i Dynamic User Interface, lavet af Mathias og Magnus. Det er ikke et produkt fra Vipps MobilePay, og turen i appen er en demo med testdata.

Se projektet: [vippswrapped.vercel.app](https://vippswrapped.vercel.app/wrapped)

Vipps Wrapped er et redesign af "del regningen"-grupper i MobilePay, inspireret af Spotify Wrapped. Gruppen deler udgifterne på en tur, og når alle har betalt, åbner turens Wrapped med højdepunkter og en rolle til hver person.

Bygget med Next.js, React, Supabase og Motion.
